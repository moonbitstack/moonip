Addresses, blocks,
and the bits
between them.

moonip reads the text forms of RFC 4291 and gives every address back in the canonical shape of RFC 5952. It works out the block an address sits in, splits blocks down, joins ranges back up, and places an address in one of the IANA special-purpose registries. Nothing here opens a socket: the two fields above are the whole job.

03 · install

two lines

Add it, then read a block.

moon add moonbitstack/moonip
main.mbtmoonbit
fn main raise {
  let block = @moonip.Prefix::parse("192.0.2.0/24")
  println(block.netmask())                                  // 255.255.255.0
  println(block.contains(@moonip.Addr::parse("192.0.2.7")))  // true
  println(block.hosts().next())                             // Some(192.0.2.1)
}
Strict on purpose. A leading zero in an IPv4 field, a dotted netmask in place of a mask length, or a zone inside a prefix is refused rather than guessed at. Every refusal says what kind of mistake it was and where it started.
