IPv4 · IPv6 · blocks · classification

Addresses, blocks,
and the bits between.

moonip reads and writes the text forms of RFC 4291, gives every address back in the canonical shape of RFC 5952, works out which block it sits in, and says whether that block is reachable. Values are immutable and can key a map. No sockets, no I/O, no dependencies.

01 / the surface

Three kinds of value,
one package.

An address, a block, and an address with a port. Everything else in the library is a function over one of those three, which is why the whole surface fits in one table.

Addr

One address

Four or sixteen bytes, plus the zone an IPv6 link-local address may carry. Compares and hashes by its bits.

  • parse · decode
  • encode · exploded
  • next · prev · unmap
  • reverse_pointer
Prefix

A block of them

An address and a mask length. Keeps the address you gave it, so the same value can stand for an interface; every question about the block works on the masked form.

  • contains · overlaps
  • hosts · subnets · supernet
  • exclude · broadcast
  • summarize · collapse
AddrPort

One end of a conversation

Text in the form a URL or a log line uses: four dotted fields with a port, or a bracketed IPv6 address with one.

  • parse · new
  • addr · port
  • brackets required for v6
  • port 0 to 65535

03 / install

One line, then an address.

The package has no dependencies of its own. Everything below is in the guide, with the output each call gives.

moon add moonbitstack/moonip
fn main raise {
  let block = @moonip.Prefix::parse("192.0.2.0/24")
  for host in block.hosts() {
    println(host)
    // 192.0.2.1 … 192.0.2.254
    break
  }
}

Two things worth knowing before you start:

A prefix keeps the address it was written with. 192.0.2.5/24 is an interface on that block; masked() is the block itself.

Refusals carry a reason and a position, so a typo can be pointed at instead of guessed at.
