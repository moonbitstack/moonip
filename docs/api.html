Addr

One address: IPv4 or IPv6, with the zone a scoped IPv6 address may carry.

pub struct Addr

An IPv4 or IPv6 address, and the zone an IPv6 scoped address may carry. The value never changes once made, compares by its bits, and can be a key in a map. IPv4 keeps its 32 bits in the low word with v4 set, so 1.2.3.4 and ::1.2.3.4 are two different addresses that never compare equal.

  v4 : Bool
  zone : String?

Prefix

An address and a mask length. Keeps the address it was written with.

pub struct Prefix

A network: an address and the number of leading bits that all addresses in it share, written 192.0.2.0/24. The address is kept as it was given, so 192.0.2.5/24 stands for "this host on that link" the way an interface does; every question about the block itself works on masked, which is the same prefix with the host bits cleared.

  net : Addr
  plen : Int32

The address as written, host bits and all.

pub fn Prefix::bits(Self) -> Int32

The length of the mask in bits: 0 to 32 for IPv4, 0 to 128 for IPv6.

pub fn Prefix::broadcast(Self) -> Addr?

The last address of the block, or None for IPv6, which has no broadcast address: the top of an IPv6 block is an ordinary unicast address.

pub fn Prefix::compare(Self, Self) -> Int32
pub fn Prefix::contains(Self, Addr) -> Bool

Whether the address falls inside the block. An IPv4-mapped IPv6 address is matched against IPv6 blocks only; unmap first if you mean the IPv4 one.

pub fn Prefix::equal(Self, Self) -> Bool
pub fn Prefix::exclude(Self, Self) -> Array[Self] raise Refused

The parts of this block that the other one does not cover, largest first. The other block only has to share the family; a block that merely touches this one at the edge leaves it whole, one that covers it leaves nothing, and one that sits over part of it leaves the surround. So the answer is always the exact difference, whatever the caller passes. ``mbt check test { let parts = @moonip.Prefix::parse("192.0.2.0/28").exclude( @moonip.Prefix::parse("192.0.2.1/32"), ) assert_eq(parts.length(), 4) assert_eq(parts[0].to_string(), "192.0.2.8/29") } ``

The complement of the mask, 0.0.0.255 or ::ffff:ffff:ffff:ffff.

pub fn Prefix::hosts(Self) -> Iter[Addr]

The addresses that can be given to an interface in the block. For IPv4 that is every address except the network and broadcast ones, with a /31 (RFC 3021) and a /32 kept whole because both ends are usable there. For IPv6 it is every address except the subnet-router anycast address at the bottom, with a /127 and a /128 kept whole. The iterator is lazy; a /0 has a great many addresses and no one wants them in an array. ``mbt check test { let usable = @moonip.Prefix::parse("192.0.2.0/30").hosts().collect() assert_eq(usable.length(), 2) assert_eq(usable[0].to_string(), "192.0.2.1") } ``

Block arithmetic that belongs to no one type: a range joined back up, and a set of blocks collapsed.

pub fn collapse(ArrayView[Prefix]) -> Array[Prefix]

The fewest blocks that hold exactly the same addresses as the ones given. Blocks of different families are collapsed separately and the IPv4 ones come first, so the answer is always exact even though a mix of families has no single ordering. ``mbt check test { let halves = [ @moonip.Prefix::parse("192.0.2.0/25"), @moonip.Prefix::parse("192.0.2.128/25"), ] let whole = @moonip.collapse(halves) assert_eq(whole.length(), 1) assert_eq(whole[0].to_string(), "192.0.2.0/24") } ``
